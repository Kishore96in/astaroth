const bool  invert_selection = false

Prune segments inside or outside the bounding box of size nn at offset rr. If the invert_selection flag is false (default), prunes segments that fall inside the bounding box. If the invert_selection flag is true, prunes segments that fall outside the bounding box.

Raises an exception if there is a segment that expands beyond the boundaries.
