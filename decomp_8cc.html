◆ decompose_hierarchical()

std::vector< ac::shape > decompose_hierarchical ( const ac::shape &  nn,
const std::vector< uint64_t > &  nprocs_per_layer 
)

Perform a layered decomposition. Returns a vector of decompositions ordered from higher granularity (i.e. core-level) to lower (i.e. node-level). The input vector nprocs_per_layer is likewise ordered from high to low granularity and indicates the number of partitions on each level of the decomposition hierarchy.

For example, a process running on 8 nodes, consisting of 4 GPUs, where each GPU is a multi-chip module of 2 devices, the decomposition can be calculated by decompose_hierarchical(nn, std::vector<uint64_t>{2, 4, 8});
